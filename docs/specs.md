# Proyecto de Prueba: Calculadora de Índice de Peligro de Incendio

## Objetivo
Crear una calculadora web que tome datos meteorológicos en tiempo real 
del endpoint /v1/situation del Defensor JRG y calcule el índice de 
peligro de incendio para Corrientes capital.

## Requisitos
- Leer datos de temperatura, humedad y viento desde la API del Defensor
- Aplicar la Regla del 30
- Mostrar semáforo de peligro
- Todo en un solo index.html
